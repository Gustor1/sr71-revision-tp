0 · Build the network (10 pts) & initialisation (−10 si ancienne config)

Câbler

  • PC-A → S1 F0/6 : câble droit
  • S1 F0/5 → R1 G0/0/0 : câble droit
  • R1 G0/0/1 → PC-B : câble croisé (auto-MDIX : un droit marche aussi)
  • Câble console bleu : USB du PC hôte → port CONSOLE de l'équipement à configurer (tu le changes de place entre S1 et R1)

PC-A et PC-B sont des VM : le câble part d'une carte réseau de l'hôte, pontée vers la VM (VirtualBox → Réseau → Accès par pont).

3 · Configure host computers (8 pts)

PC-A · Windows 8 (VM)

Set IPv4 address + gateway (2) — interface graphique : Win+R → ncpa.cpl → clic droit carte → Propriétés → IPv4 → 172.16.2.10 / 255.255.255.0 / 172.16.2.1. Ou en cmd administrateur :

netsh interface ipv4 set address name="Ethernet" static 172.16.2.10 255.255.255.0 172.16.2.1
netsh advfirewall set allprofiles state off
ipconfig

Write down the IPv6 GUA (2) : dans ipconfig, la ligne « Adresse IPv6 . . . : 2001:fe:ab:2:xxxx:xxxx:xxxx:xxxx ». Pas la « temporaire », pas fe80.

PC-B · Linux (VM)

ip a                                          # nom de la carte (enp0s3 ?)
sudo ip addr add 172.16.3.10/24 dev enp0s3
sudo ip route add default via 172.16.3.1
ip -6 addr show dev enp0s3                    # GUA = inet6 2001:fe:ab:3:… scope global

💡 Pas de GUA ? → ipv6 unicast-routing manque sur R1 (pas de RA), ou l'interface du routeur est down. Attends ~10 s après l'avoir ajouté.

⚠ Les 10 pièges de cette annale

  1. Oublier d'écrire son nom (−5) et de mettre son nom dans le hostname.
  2. Ne pas effacer l'ancienne config (−10) → toujours show running-config au début.
  3. Oublier le SDM → l'IPv6 du switch est refusée.
  4. crypto key avant hostname/ip domain-name → refusé.
  5. min-length 5 : tout mot de passe < 5 caractères est refusé.
  6. Oublier no shutdown sur les interfaces du routeur (éteintes par défaut).
  7. Oublier ipv6 unicast-routing → les PC n'ont pas de GUA « Auto ».
  8. Pare-feu Windows actif → les pings vers PC-A échouent.
  9. Ping d'une link-local sans %index (Windows) ou -I enp0s3 (Linux).
  10. Fermer la session SSH ou nettoyer avant que le prof ait corrigé.

Vocabulaire des énoncés

Simulateur IOS

Une console comme dans PuTTY. Choisis une mission, tape les commandes ; les objectifs se cochent tout seuls. Il gère les abréviations (conf t, sh ip int br), l'aide ?, la touche Tab et les erreurs typiques (DNS, SDM, clé RSA, min-length…).

Labo de câblage

Choisis le type de câble, clique sur un port puis sur l'autre. Respecte les numéros de ports de l'énoncé. Clique sur un câble pour le retirer.

🔵 Droit

Entre types différents : PC ↔ switch, routeur ↔ switch.

🟠 Croisé

Entre mêmes types : switch ↔ switch, PC ↔ routeur (PC et routeur sont tous deux des « terminaux »). L'auto-MDIX rend souvent le droit fonctionnel, mais l'énoncé attend la théorie.

🟣 Console

Câble bleu RJ45 ↔ USB/série, de l'hôte vers le port CONSOLE (pas AUX). PuTTY : Serial, 9600.

Exercices

Six entraînements courts. Tes meilleurs scores sont gardés sur la page d'accueil.

Examen blanc

Même structure et même barème que l'annale, avec des adresses, masques, mots de passe et ports tirés au hasard. Fais-le chrono en main (sur papier ou dans le simulateur), puis ouvre la correction.
